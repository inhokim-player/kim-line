# RiskNow — 로그인 없이 누구나 보는 리스크 현황판

계정도, 로그인도 없습니다. 접속하는 즉시 실시간 국가 통계를 보고, 8개 질문으로
내 리스크 유형을 진단하고, 그 결과를 매일 체크인하며 관리할 수 있어요. 개인 데이터는
서버가 아니라 이 브라우저(`localStorage`)에만 저장됩니다.

## 화면 흐름

```
처음 접속
  → 랜딩 (풀스크린 실시간 통계 대시보드 + 진단 CTA + 8문항 퀴즈 + 보험사 섹션)
  → 퀴즈 완료 → "이 결과로 매일 관리 시작하기" 클릭
  → 즉시 대시보드로 진입 (로그인 절차 없음)

같은 브라우저로 재방문
  → 오늘 기록이 없으면 5문항 빠른 체크인
  → 오늘 기록이 있으면 바로 대시보드

기록 초기화
  → 대시보드 우측 상단 "기록 초기화"로 이 브라우저의 모든 데이터를 지우고 랜딩으로 복귀
```

## 왜 로그인이 없나

계정이 없으면 서버에 개인 습관 데이터가 쌓이지 않습니다. 대신 기기를 바꾸면 기록이
이어지지 않는다는 트레이드오프가 있어요. 나중에 "여러 기기에서 이어보기"가 필요해지면
`src/lib/localStore.js`의 함수들을 Supabase 등 백엔드 호출로 교체하면 됩니다 — 나머지
컴포넌트는 이 파일에만 의존하도록 분리되어 있습니다.

## 테스트

```bash
npm test
```

- `kst.test.js` — 한국시간 자정 리셋, 윤년 자동 계산, 방문자 시간대 무관성 검증
- `livePace.test.js` — 실시간 카운터가 드리프트 없이 절대 시각 기준으로 재계산되는지 검증
- `riskCalculator.test.js` — 리스크 점수·보험료 계산 경계값 검증
- `riskTypes.test.js` — 문항 집계, 16유형 판정, 성향 분석 로직 검증
- `QuestionCard.test.jsx` / `Quiz.test.jsx` / `DailyCheckin.test.jsx` — 실제 클릭 흐름이
  끝까지 완주해 올바른 결과를 내는지 검증

## 핵심 개념

- **실시간 통계 히어로**: 통계청 연간 사망자 수를 한국시간(KST) 기준으로 초 단위 환산한
  "추정 페이스" 카운터. 국내 10대 사망원인 그래프도 첫 화면에 바로 보입니다 (`landing/Hero.jsx`).
- **진단 → 결과 → 성향 분석**: 8문항 퀴즈로 16가지 리스크 유형 판정, 결과 화면에 4개 축
  (운전·수면·활력·마음) 점수와 맞춤 코멘트까지 표시 (`riskTypes.js`의 `buildArchetype`,
  `analyzeTraits`).
- **일일 체크인**: 재방문 시 5문항으로 빠르게 오늘 데이터를 기록, 대시보드 게이지가
  애니메이션으로 갱신됩니다.
- **국가 통계 비교**: 대시보드에서 내 약점 지표에 맞는 국가 통계를 자동으로 매칭해
  보여줍니다 (`NationalStats.jsx`).

```bash
npm install

```

```bash
npm run build
```

- Build command: `npm run build`
- Build output directory: `dist`
- 환경변수 불필요 (백엔드가 없습니다)

## 국가 통계 갱신

`src/lib/nationalStats.js`는 통계청 2024년 발표 기준 고정 스냅샷입니다. 최신 수치로
갱신하려면 [KOSIS Open API](https://kosis.kr/openapi)에서 API 키를 발급받아 값을
교체하세요.
